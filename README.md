# Learning Java Core

A personal, interview-focused **Java Core** course (mentored). Goal: job-ready for Java backend roles (India market), optimized for what's actually tested in interviews. Scope is Java Core only — Spring Boot is a separate project.

## How to resume

Just start a session in this repo and say **"let's continue"** (or "next module", "teach me X"). The `java-core-mentor` skill loads the teaching method automatically and picks up from **"Next up"** in `progress.md`.

## Where everything lives

| Path | What it is |
|------|-----------|
| `.claude/skills/java-core-mentor/SKILL.md` | **The mentor** — learner brief, teaching method, rules, git discipline (single source of truth for *how* the course runs) |
| `progress.md` | **Tracker** — module checklist, current status, struggle log, interview drill queue |
| `notes.md` | **Interview refresher** — concise, skim-before-interview takeaways, one section per module |
| `modules/module-XX-name.md` | **Full lesson** per module — every concept, code, "Under the Hood", gotcha, PHP contrast |
| `modules/module-XX-name/*.java` | **Runnable demos** for each module (predict-then-run) |

## Structure of the course

10 of ~29 modules across 8 phases are complete (Phases 0 and 1 done). See `progress.md` for the full roadmap and live status.
